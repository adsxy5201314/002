## 摘要

本作品面向低空经济中的城市应急医疗物资投送场景，设计并实现了一个无人机智能飞行仿真系统。系统以医院到社区应急点的低空航线为任务背景，构建包含建筑群、学校禁飞区、通信设施缓冲区、巡检无人机通道、临时吊装设备和医疗直升机进近风险的三维城市空域。作品使用三维 A* 算法生成全局航线，结合三维激光雷达扫描与局部排斥场完成动态避障，并加入前视视觉识别仿真，用于识别建筑、禁飞空域、动态障碍和目标点。最终输出 3D 轨迹截图、演示动图、实验指标和自动验证报告，用于验证方案的可行性与安全性。

## 一、绪论

### 1.1 低空经济应用背景

低空经济强调在城市和产业场景中使用无人机、eVTOL、低空监测平台等载具完成巡检、物流、救援、农业、安防等任务。与传统地面交通相比，无人机具备越过道路拥堵、快速部署和点对点飞行的优势，尤其适合应急药品、血液样本、AED 配件、小型检测试剂等轻量高时效物资投送。

### 1.2 实际痛点

城市应急物资投送并不是简单的“直线飞过去”。真实低空环境中存在建筑物遮挡、学校/医院等敏感区域禁飞、通信塔等设施安全缓冲区、其他无人机或临时施工吊装等动态风险。如果仅依赖人工规划航线，响应速度慢，并且难以实时处理突发障碍；如果只做概念方案而缺少可视化验证，也难以证明方案可落地。

### 1.3 作品目标

本作品目标是构建一个可运行、可解释、可视化的无人机智能飞行仿真原型，展示无人机在城市低空环境中完成应急物资投送的全过程。作品重点体现“三维场景建模、空间路径规划、自动避障、仿真验证、结果指标”之间的闭环。

## 二、方案设计

### 2.1 应用场景

设定任务为：医院发出应急小件医疗物资，无人机从起点起飞，飞往社区应急服务点。途中需要避开建筑群、学校禁飞区、通信设施缓冲区，并对低空巡检无人机和临时吊装设备做动态避障。

### 2.2 系统组成

系统分为四个模块：

1. 场景建模模块：使用三维坐标描述城市街区、楼体障碍、禁飞空域柱和动态球形障碍。
2. 全局路径规划模块：使用三维 A* 算法在空间栅格中搜索安全航线。
3. 局部避障模块：使用简化三维激光雷达射线扫描，依据障碍距离生成排斥向量。
4. 视觉识别模块：模拟机载前视相机，对建筑、禁飞区、动态障碍和目标点进行识别并记录置信度。
5. 可视化验证模块：输出轨迹图、演示动图、JSON 指标和 pass/fail 验证报告。

### 2.3 创新点

作品将低空经济的真实约束转化为仿真要素，而不是只展示普通路径规划。场景中同时包含静态障碍、禁飞区、安全缓冲区和动态障碍，能够体现城市低空航线规划的综合复杂度。仿真结果还输出最小安全距离、飞行时间和航程，便于评价方案是否“能飞、可用、可解释”。

## 三、技术原理

### 3.1 场景建模

仿真空域尺寸为 120 m × 80 m × 42 m。建筑物使用三维盒体表示，禁飞区和通信设施保护区使用贯穿低空空域的禁飞柱表示，并在路径规划时外扩安全缓冲盒，避免无人机贴边飞行。动态障碍使用球形区域表示，其中心点随时间按正弦轨迹移动，模拟其他低空设备、施工吊装设施或医疗直升机进近的活动范围。

### 3.2 A* 全局路径规划

A* 算法在三维空间栅格上搜索从起点到目标点的可行路径。每个栅格节点最多连接 26 个相邻方向，移动代价按三维欧氏距离计算，并加入巡航高度偏好，使无人机能够自动爬升到更安全的低空高度。评价函数为：

```text
f(n) = g(n) + h(n)
```

其中 `g(n)` 是从起点到当前节点的累计代价，`h(n)` 是当前节点到目标点的三维欧氏距离估计。算法会跳过楼体、禁飞柱及其安全缓冲盒，从而获得满足静态安全约束的初始航线。

### 3.3 航点简化与前视跟踪

原始 A* 路径由大量相邻栅格点组成，不适合直接作为飞行控制目标。程序使用视线检测对路径进行简化：如果两个远距离节点之间的线段不穿越障碍缓冲区，就保留更远节点，删除中间冗余节点。这样可减少频繁转向，让航线更接近实际飞控中的航点序列。

实际飞行控制部分采用前视航点跟踪方式：无人机不只盯着最近的栅格点，而是选取前方若干节点作为局部目标，形成更平滑的速度方向。这样可以避免在密集栅格点之间频繁抖动，同时又不会像过度平滑路径那样在建筑拐角处“抄近路”。

### 3.4 简化激光雷达局部避障

飞行过程中，无人机以当前位置为中心进行三维射线扫描，射线覆盖水平、上仰、下俯和垂直方向。射线命中楼体、禁飞柱、空域边界或动态障碍时，系统记录命中点与距离。距离越近，局部排斥向量越强；随后将“指向下一航点的吸引向量”和“远离障碍的排斥向量”合成为飞行控制指令。

```text
u = k_att * direction_to_waypoint + k_rep * obstacle_repulsion
```

这种方法比只按全局路径飞行更稳健，因为它能在运行中响应动态障碍。

### 3.5 前视视觉识别仿真

为满足“视觉识别算法仿真开发与验证”的要求，程序增加了简化机载相机模型。相机以无人机当前飞行指令方向为前方，在限定视场角和识别距离内检测目标，并为每个识别结果输出类型、名称、距离、方位角和置信度。识别对象包括：

```text
building / no_fly_zone / dynamic_airspace_obstacle / delivery_target
```

视觉识别结果不会替代激光雷达避障，而是作为独立感知链路参与调试验证：验证报告会检查是否识别到动态障碍和最终目标点，从而说明系统不仅“能飞过去”，还具备基本的环境感知闭环。

### 3.6 调试与验证

程序会自动生成 `outputs/validation_report.json`，对以下项目给出 pass/fail 结论：

| 验证项 | 验证内容 |
| --- | --- |
| path_planning | 三维 A* 是否生成有效航线和简化航点 |
| flight_control | 是否成功到达、是否碰撞、速度是否超过限制 |
| lidar_obstacle_avoidance | 最小安全距离是否达标、雷达是否产生有效扫描 |
| vision_recognition | 是否识别到动态障碍和投送目标 |
| altitude_envelope | 飞行高度是否始终在低空空域边界内 |

这种验证方式比只看动画更可靠，因为它把“成功、避障、识别、限速、限高”等要求变成可复查的结构化指标。

## 四、实施过程

### 4.1 开发环境

本项目使用 Python 实现，依赖 `numpy`、`matplotlib`、`pillow`。当前文件夹已经配置 `.venv` 虚拟环境，并提供 `run_demo.ps1` 一键运行脚本。

### 4.2 项目文件

核心程序位于 `src/drone_delivery_sim.py`。运行脚本后会自动生成 `outputs/final_trajectory.png`、`outputs/drone_delivery_demo.gif`、`outputs/drone_delivery_demo.mp4`、`outputs/summary.json` 和 `outputs/validation_report.json`。其中 PNG 可作为报告插图，MP4 可作为演示视频材料，验证报告可作为调试与可靠性说明材料。

### 4.3 运行方法

在 PowerShell 中进入项目目录后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_demo.ps1
```

## 六、总结

本作品围绕低空经济中的城市应急物资投送痛点，完成了从需求分析到仿真验证的完整设计。三维 A* 全局路径规划解决了静态楼体和禁飞空域约束下的航线生成问题；三维激光雷达局部避障提高了面对动态障碍时的安全性；前视视觉识别补充了环境感知能力；自动验证报告让调试过程更可复查。后续可进一步加入风场扰动、电量约束、多无人机协同和真实地图数据接入。
