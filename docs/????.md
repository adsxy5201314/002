## 摘要

本作品面向低空经济中的城市应急医疗物资投送场景，设计并实现了一个无人机智能飞行仿真系统。系统以医院到社区应急点的低空航线为任务背景，构建包含建筑群、学校禁飞区、通信设施缓冲区、巡检无人机通道和临时吊装设备的二维城市空域。作品使用 A* 算法生成全局航线，并结合简化激光雷达扫描与局部排斥场完成动态避障，最终输出轨迹截图、演示动图和实验指标，用于验证方案的可行性与安全性。

## 一、绪论

### 1.1 低空经济应用背景

低空经济强调在城市和产业场景中使用无人机、eVTOL、低空监测平台等载具完成巡检、物流、救援、农业、安防等任务。与传统地面交通相比，无人机具备越过道路拥堵、快速部署和点对点飞行的优势，尤其适合应急药品、血液样本、AED 配件、小型检测试剂等轻量高时效物资投送。

### 1.2 实际痛点

城市应急物资投送并不是简单的“直线飞过去”。真实低空环境中存在建筑物遮挡、学校/医院等敏感区域禁飞、通信塔等设施安全缓冲区、其他无人机或临时施工吊装等动态风险。如果仅依赖人工规划航线，响应速度慢，并且难以实时处理突发障碍；如果只做概念方案而缺少可视化验证，也难以证明方案可落地。

### 1.3 作品目标

本作品目标是构建一个可运行、可解释、可视化的无人机智能飞行仿真原型，展示无人机在城市低空环境中完成应急物资投送的全过程。作品重点不在复杂三维建模，而在说明“任务场景、算法逻辑、仿真验证、结果指标”之间的闭环。

## 二、方案设计

### 2.1 应用场景

设定任务为：医院发出应急小件医疗物资，无人机从起点起飞，飞往社区应急服务点。途中需要避开建筑群、学校禁飞区、通信设施缓冲区，并对低空巡检无人机和临时吊装设备做动态避障。

### 2.2 系统组成

系统分为四个模块：

1. 场景建模模块：使用二维坐标描述城市街区、建筑障碍、禁飞区和动态障碍。
2. 全局路径规划模块：使用 A* 算法在栅格地图中搜索安全航线。
3. 局部避障模块：使用简化激光雷达射线扫描，依据障碍距离生成排斥向量。
4. 可视化验证模块：输出轨迹图、演示动图和 JSON 指标。

### 2.3 创新点

作品将低空经济的真实约束转化为仿真要素，而不是只展示普通路径规划。场景中同时包含静态障碍、禁飞区、安全缓冲区和动态障碍，能够体现城市低空航线规划的综合复杂度。仿真结果还输出最小安全距离、飞行时间和航程，便于评价方案是否“能飞、可用、可解释”。

## 三、技术原理

### 3.1 场景建模

仿真地图尺寸为 120 m × 80 m。建筑物和禁飞区用矩形区域表示，并在路径规划时外扩安全缓冲区，避免无人机贴边飞行。动态障碍使用圆形区域表示，其中心点随时间按正弦轨迹移动，模拟其他低空设备或施工吊装设施的活动范围。

### 3.2 A* 全局路径规划

A* 算法在栅格地图上搜索从起点到目标点的最短可行路径。每个栅格节点有八个相邻方向，直向移动代价为 1，斜向移动代价为 √2。评价函数为：

```text
f(n) = g(n) + h(n)
```

其中 `g(n)` 是从起点到当前节点的累计代价，`h(n)` 是当前节点到目标点的欧氏距离估计。算法会跳过建筑物、禁飞区及其安全缓冲区，从而获得满足静态安全约束的初始航线。

### 3.3 航点简化与前视跟踪

原始 A* 路径由大量相邻栅格点组成，不适合直接作为飞行控制目标。程序使用视线检测对路径进行简化：如果两个远距离节点之间的线段不穿越障碍缓冲区，就保留更远节点，删除中间冗余节点。这样可减少频繁转向，让航线更接近实际飞控中的航点序列。

实际飞行控制部分采用前视航点跟踪方式：无人机不只盯着最近的栅格点，而是选取前方若干节点作为局部目标，形成更平滑的速度方向。这样可以避免在密集栅格点之间频繁抖动，同时又不会像过度平滑路径那样在建筑拐角处“抄近路”。

### 3.4 简化激光雷达局部避障

飞行过程中，无人机以当前位置为中心进行 360 度射线扫描。射线命中建筑、禁飞区、地图边界或动态障碍时，系统记录命中点与距离。距离越近，局部排斥向量越强；随后将“指向下一航点的吸引向量”和“远离障碍的排斥向量”合成为飞行控制指令。

```text
u = k_att * direction_to_waypoint + k_rep * obstacle_repulsion
```

这种方法比只按全局路径飞行更稳健，因为它能在运行中响应动态障碍。

## 四、实施过程

### 4.1 开发环境

本项目使用 Python 实现，依赖 `numpy`、`matplotlib`、`pillow`。当前文件夹已经配置 `.venv` 虚拟环境，并提供 `run_demo.ps1` 一键运行脚本。

### 4.2 项目文件

核心程序位于 `src/drone_delivery_sim.py`。运行脚本后会自动生成 `outputs/final_trajectory.png`、`outputs/drone_delivery_demo.gif`、`outputs/drone_delivery_demo.mp4` 和 `outputs/summary.json`。其中 PNG 可作为报告插图，MP4 可作为演示视频材料。

### 4.3 运行方法

在 PowerShell 中进入项目目录后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_demo.ps1
```

## 六、总结

本作品围绕低空经济中的城市应急物资投送痛点，完成了从需求分析到仿真验证的完整设计。A* 全局路径规划解决了静态建筑和禁飞区约束下的航线生成问题；简化激光雷达局部避障提高了面对动态障碍时的安全性；可视化输出增强了方案展示效果。后续可进一步扩展为三维仿真，加入风场扰动、电量约束、多无人机协同和真实地图数据接入。
