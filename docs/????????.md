# AIGC 辅助开发提示词与调试记录

## 一、使用目标

根据课程期末要求，生成一个贴合低空经济场景、具备可运行代码和可视化成果的无人机智能飞行仿真作品。

## 二、核心提示词摘要

```text
请根据“飞行智能控制仿真与场景实践（产业）”期末作品要求，
围绕低空经济实际应用设计一个无人机仿真作品。
作品需要包含调研背景、技术原理、实施思路、成果总结，
并尽量有可运行的仿真代码和可视化演示。
```

```text
实现一个城市低空应急物资投送仿真：
1. 建模建筑物、禁飞区和动态障碍；
2. 使用 A* 进行全局路径规划；
3. 使用简化激光雷达和局部排斥场进行动态避障；
4. 输出轨迹截图、GIF 动画和实验指标。
```

## 三、调试记录

1. 当前文件夹初始为空，因此先创建 `.venv` 虚拟环境和项目结构。
2. PDF 路径包含中文，PowerShell 管道默认编码会造成字符替换，因此改用 Python 遍历桌面 PDF 文件并按文件大小定位目标文件。
3. PDF 正文包含少量特殊 Unicode 字符，切换 Python 标准输出为 UTF-8 后成功提取课程要求。
4. 仿真采用二维地图而非复杂三维引擎，保证课堂展示时可稳定运行并快速生成可视化结果。
